#Requisitos funcionais

    RF01_O sistema permite cadrastrar um chamado;
    RF01_O sistema deve listar todos os dado cadastrados;
    RF03_O sistema deve permitir alterar o status do chamado;
    RF04_O sistema deve permitir filtrar chamados por status.

    RNF01_O sistema deve funcionar no navegador;
    RNF02_A interface deve ser simples e responsiva;
    RNF03_Os dados devem ser armazenados localmente no navegador;
    RNF04_O código deve estar versionado no Github.
